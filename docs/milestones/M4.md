# M4 Release 1.0 – status

Nov 11, 2026 · built and checked on Linux (X11, NVIDIA RTX 3080, Qt 6.12; Flatpak on KDE 6.11)

**Released:** v0.9.0 (Linux preview), then **v1.0.0 for Linux** on Nov 11, 2026.

**Gate status: passed for Linux.** Specification v1.2 makes 1.0 the Linux release: a Flatpak,
media keys, diagnostics, third-party notices, user documentation and measured performance
budgets, used without errors by the maintainer. Everything below moves to milestone M5
(version 1.1):

- **Windows:** the LGPL libmpv bundle is now cross-built with MinGW-w64
  (`third_party/mpv/Dockerfile.windows`) and the app builds with MSVC in CI (job
  `app-windows`, portable package). Not run on Windows yet ([first-run
  checklist](../testing/windows-first-run.md)). Still missing: direct mode with HDR10
  passthrough, MSIX and winget, code signing (1.0 ships unsigned), SMTC media keys.
- **Signing:** Flathub signs its own builds; a key for signing GitHub release checksums and a
  Windows code-signing certificate have to come from the maintainer.
- **Hardware:** the scroll budget on integrated graphics (Intel, AMD), and Wayland.
- **Flathub submission:** screenshots for the AppStream metadata, the cargo sources as a
  generated manifest instead of a vendored folder, and a public repository.
- **Gamepads** (open since M1): Qt 6 has no gamepad module; needs SDL or similar.

## Performance budgets

`crates/library/examples/bench_seed.rs` writes a library of 5,000 movies, each with its own
360 px poster thumbnail, as the scanner and artwork worker leave them. `coyotl --benchmark
startup|scroll` measures and prints one JSON line. CI runs both on every push under Xvfb with
software rendering; those numbers only track regressions.

| Budget (SPEC 9) | Result here | Notes |
| --- | --- | --- |
| Cold start to an interactive Home in under 2 s (warm disk cache) | 0.73 s in the Flatpak (release build), 0.88–1.0 s in a local RelWithDebInfo build | The Home rows used to arrive 1.2 s late: "recently added" looked up each item's poster without an index. Migration 3 adds `artwork(item_id, role)`. |
| Poster grid at 60 Hz without dropped frames, 5,000 items | 1,199 frames, 0 dropped; p99 17.4 ms and worst 19.4 ms in the Flatpak | NVIDIA RTX 3080. 20 s at 4,000 px/s, with pages fetched while scrolling. **Integrated graphics not measured yet.** |

## Deviations from the specification

- **Flatpak sources.** Rust crates are vendored by `packaging/flatpak/build.sh` instead of a
  `cargo-sources.json`; Flathub needs the generated-sources form at submission.
- **Notices in the Flatpak** are generated before the build (the SDK has no `cargo-about`) and
  passed in with `COYOTL_NOTICES_FILE`.
- **MPRIS Stop** leaves the player like Escape does, so progress is saved.
- **AppImage** (second Linux format) is not started.

## How to check

```bash
packaging/flatpak/build.sh --install && flatpak run io.github.blub3.Huehuecoyotl
```

```bash
busctl --user call org.mpris.MediaPlayer2.coyotl /org/mpris/MediaPlayer2 org.mpris.MediaPlayer2.Player PlayPause
```

```bash
cargo run --release -p huehuecoyotl-library --example bench_seed -- /tmp/bench 5000 && build/app/coyotl --data-dir /tmp/bench --benchmark scroll
```

```bash
coyotl-cli --data-dir DIR diagnostics /tmp/diag.txt
```
