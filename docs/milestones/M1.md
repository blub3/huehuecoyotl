## Decisions taken during M1

- **`crates/core` added.** The headless API lives in its own crate, and `crates/core-api` only holds the `cxx` bridge. Otherwise the CLI harness would have to link the C++ side of the bridge.
- **Sidecar subtitles via `sub-add`, after the file loads.** It carries the language the core parses from the file name; the remembered subtitle language is applied once all sidecars are known.
- **Language codes normalised in the core** (`de`, `deu`, `ger` → `ger`), and mpv gets every spelling, so container tags and file names match.
- **Models update rows in place on refresh**, so keyboard focus survives a re-query (found when testing with the keyboard).
- **qmltc (QML type compiler) is off**; qmlcachegen compiles the QML. qmltc is still a technology preview and rejects valid code.

## Known gaps (carried into M2)

- Gamepad input (above).
- Place names from the core ("Home", "Computer") are not translated.
- Media keys work when the window has focus; system-wide media keys (MPRIS, SMTC) are planned with the rest of the desktop integration.
- Screensaver inhibit uses `org.freedesktop.ScreenSaver`; the Flatpak portal comes with packaging (M4).
- Logs go to `<data>/logs/coyotl.log` without rotation yet.
