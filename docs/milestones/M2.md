## Measurements

- **Grid scrolling, 5,006 items:** 400 rows (1,600 titles, about a dozen page fetches) at key-repeat speed. Render work per frame: median 0 ms, p99 6 ms, max 9 ms. GUI-thread polish: max 1 ms. The 16 ms budget at 60 Hz is never at risk. Caveats: RTX 3080, not integrated graphics, and no poster images (no key) were decoded.
- **Rescanning 5,000 unchanged files:** under 3 s including app start (headless CLI).

## Decisions taken during M2

- **reqwest on rustls with the `ring` provider, OS certificate store** (`rustls-platform-verifier`). `aws-lc-rs` would need CMake and NASM on Windows and brings the OpenSSL licence. New allowed licence: CDLA-Permissive-2.0, for Mozilla's CA bundle as data.
- **Schema migration 2:**
  - library folders as `source` rows with a `root`;
  - item columns for overview, rating, runtime, `added_at` and a grouping key;
  - a `match_candidate` table;
  - `job.dedupe` and `job.last_error`.
- **Lock semantics:** a lock protects the chosen TMDB id. Details for that id apply in full; anything else keeps the title and year.
- **Missing year in a file name is neutral** in scoring, so a unique exact title matches. Identical titles still go to review through the margin rule.
- **Library folders and plain folder browsing share play state.** A file opened from the Sources browser that lies inside a library folder uses the library item.
- **Section pages are `Component`s, not URLs.** A URL `initialItem` silently stayed empty, and components are checked by qmllint.

## Known gaps (carried forward)

- **Live TMDB check:** needs a key. With `COYOTL_TMDB_KEY` set, `coyotl-cli library add DIR` matches headless.
- **Track probing** (scan step 6, lazy probing of tracks and HDR flags) is not done; the player shows the tracks at play time.
- **`.nfo` files** are not read yet.
- **No folder change notifications:** libraries rescan at start and on demand.
- **Multi-part movies** are grouped into one item, but playback starts the largest file only, without chaining parts.
- **TMDB logo:** the official asset is not yet in place; a text mark stands in for it.
- **No new Qt Quick tests** for the grids, detail pages or rail.
- **Gamepad input** is still open (from M1).
