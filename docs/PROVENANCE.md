# Provenance and licence boundaries

What in this repository is not plain Apache-2.0 source, where it comes from, and which terms apply.
Check this page when making a release. Third-party libraries and Rust crates are listed in
`THIRD_PARTY_NOTICES.txt` (`tools/notices.sh`).

| Material | Where | Origin | Terms |
|---|---|---|---|
| Source code | everything not listed below | Written for this project | Apache-2.0 (`LICENSE`) |
| Logo | `assets/logo/huehuecoyotl.png` | Generated with ChatGPT (OpenAI), as the maintainer recorded on Nov 23, 2026 | The terms in `assets/logo/LICENSE`, as far as rights in it exist. Copyright in purely AI-generated images is uncertain, so the file cannot be relied on to stop others from reusing the image |
| TMDB logo | `assets/tmdb/` | TMDB's official logo page; source and checksum in `assets/tmdb/README.md` | Belongs to TMDB, used for attribution under its API terms |
| Generated icons | `packaging/icons/`, `packaging/windows/msix/Assets/` | Made from the logo by `tools/make-icons.py` | Same as the logo |
| FFmpeg bindings | `crates/probe/src/ffi_types.rs` (FFmpeg 8.1), `ffi_types_71.rs` (7.1) | Generated by `tools/gen-ffmpeg-bindings.sh` with bindgen from FFmpeg's headers: types and constants only | Derived from headers under LGPL-2.1-or-later, so treated as LGPL-2.1-or-later and not as Apache-2.0 |
| Patched `smb` crate | `third_party/smb` | Published crate with one version change (`third_party/smb-PATCH.md`) | MIT, upstream notice in `third_party/smb/LICENSE.md` |
| Build recipes for libmpv | `third_party/mpv` | Written for this project; they download pinned upstream sources | Apache-2.0 for the recipes; the built libraries keep their own licences |

## How the logo reaches users

Packages carrying the icons also carry `THIRD_PARTY_NOTICES.txt`, which includes the logo's terms.
The app shows that file under Settings → About.

## Test fixtures

Checked on Nov 23, 2026. No fixture contains a copied description, biography or image.

| Fixture | Content | Status |
|---|---|---|
| `crates/metadata/tests/fixtures/mb_*.json` | MusicBrainz core data: names, dates, identifiers | Facts; MusicBrainz core data is CC0 |
| `ol_work.json` | Book facts with a description written for the test, marked "Fixture text" | Synthetic text |
| `ol_search_*.json` | Open Library titles, authors, years, identifiers | Facts only |
| `tadb_*.json`, `fanart_artist.json` | "Example Band", with biographies written for the test and local image URLs | Synthetic |
| `crates/core/tests/fixtures/*.json` | Example show and search answers without descriptions | Synthetic structure |
| `crates/scanner/tests/fixtures/filenames.tsv` | File names for the parser | Names and numbers only |
| `tests/servers/fixtures` | Generated at test time from a seeded random source; not committed | Generated |

New fixtures use made-up text. Do not commit descriptions, biographies, reviews or images copied
from a service unless their licence allows it, and record that here.

## AI-assisted code

Parts of this project are written with AI assistance. Such commits carry a `Co-Authored-By` trailer
naming the model. No code is known to have been copied from an external source apart from the
material listed above. When code is copied or closely adapted from elsewhere, keep its notice and
add it to this page.
