# TMDB logo

`tmdb-blue-short.svg` is TMDB's "Primary short (blue)" logo, unchanged, from
<https://www.themoviedb.org/about/logos-attribution> (downloaded Nov 23, 2026; its SHA-256 is
`8e7b30f73a4020692ccca9c88bafe5dcb6f8a62a4c6bc55cd9ba82bb2cd95f6c`).

`tmdb-blue-short.png` is the same logo rendered at 640 × 83 pixels, keeping its proportions and
colours, because the app does not use the Qt SVG module.

The logo belongs to TMDB. It is **not** covered by this project's Apache License. TMDB provides it
for applications that use its data to attribute TMDB as the source, under its
[API terms](https://www.themoviedb.org/api-terms-of-use) and
[FAQ](https://developer.themoviedb.org/docs/faq). The app shows it less prominently than its own
logo, next to the notice "This product uses the TMDB API but is not endorsed or certified by TMDB."
